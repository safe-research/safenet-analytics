# Safenet

Activity of the Safenet production network ("Aegis") on Gnosis Chain. Safenet checks Safe transactions before they are signed: a transaction is proposed, Sentinels check it, and validators attest it once the check approves it.

Queries, charts and this text are managed in [safe-research/safenet-analytics](https://github.com/safe-research/safenet-analytics); changes made here in Dune are overwritten. The earlier Beta network has its own dashboard: [safenet-beta](https://dune.com/safe/safenet-beta).
